## 규칙

관련된 ai-automation 스킬이 있으면 어떤 답이나 행동보다 먼저 그 스킬을 실행한다.
확인 질문을 하기 전에도 마찬가지다.

## 설정 확인

`~/.config/ai-automation/config.json`을 읽는다.
파일이 없거나 읽을 수 없으면 다른 ai-automation 스킬보다 먼저 `references/setup.md`를 따른다.

## 어디에 무엇이 있나

아래 경로는 플러그인 루트(이 파일에서 두 단계 위) 기준이다.

| 무엇 | 위치 | 쓰는 법 |
|------|------|---------|
| 스킬 | `skills/<name>/SKILL.md` | 이름으로 실행한다 |
| 공유 지식 | `knowledge/INDEX.md` | 색인을 읽고, 이번 요청에 필요한 파일만 읽는다 |
| 요청 → 저장소 | `knowledge/routing.md` | 요청이 저장소나 서비스를 가리킬 때 읽는다 |
| 에이전트 | `agents/<name>.md` | 파일 본문을 프롬프트로 서브에이전트를 띄운다 |

읽을 때는 플러그인 루트를 쓴다.
스킬·지식·에이전트 파일을 고칠 때는 설정의 `pluginRepository`(ai-automation 저장소의 로컬 clone)에 쓴다.
플러그인 루트는 캐시라서 거기에 쓴 내용은 업데이트할 때 사라진다.

## 모든 스킬에 적용

ai-automation 스킬은 첫 단계를 시작하기 전에 아래를 따른다.
업무 스킬은 첫 줄에서 이 절을 가리키므로, 이 스킬을 거치지 않고 바로 불려도 적용된다.

1. **필수 규칙.** `knowledge/INDEX.md`의 "필수 규칙"에 있는 파일을 모두 읽고 지킨다.
   - 한 세션에서 이미 읽었으면 다시 읽지 않는다.
   - 스킬 본문과 필수 규칙이 부딪치면 필수 규칙을 따른다.
   - 사람이 필수 규칙과 다르게 하라고 하면 어느 규칙과 다른지 알리고, 확인을 받은 뒤에 따른다.
2. **지식.** `knowledge/INDEX.md`를 읽는다.
   - 스킬의 `## 참고 지식`에 적힌 파일은 반드시 읽는다.
   - 나머지 주제 파일은 이번 일에 필요한 것만 읽는다. 필요 없다고 판단하면 읽지 않아도 된다.
   - 사실을 말하거나 결정할 때 근거가 될 주제 파일이 색인에 있으면 기억이나 추측 대신 그 파일을 읽는다.
3. **찾은 자료 저장.** 작업 중에 조사하거나 사람에게 들은 사실·자료를 다음에도 쓸 것 같으면 `knowledge/INDEX.md`의 "추가·갱신 규칙"대로 주제 파일에 저장하거나 고친다.
   - 대화에만 남기지 않는다.
   - 저장했으면 어느 파일에 무엇을 더하거나 바꿨는지 한 줄로 알린다.

## 하네스별 차이

- Codex: `adapters/codex/README.md`
- Gemini CLI: `adapters/gemini/README.md`

Claude Code와 Cursor는 따로 맞출 것이 없고 `agents/`를 직접 읽는다.
Codex와 Gemini CLI는 세션 시작 훅이 없고 `agents/`를 읽지 않는다.
에이전트가 필요하면 `agents/<name>.md`를 읽고 그 본문으로 서브에이전트를 띄운다.
