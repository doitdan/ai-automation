# 충돌 풀기

충돌은 같은 파일의 같은 부분을 나와 다른 사람이 다르게 고쳤을 때 난다.
말없이 한쪽을 고르지 않는다.

1. `git diff --name-only --diff-filter=U`로 충돌한 파일 목록을 보여 준다.
2. 파일 하나, 충돌 부분 하나씩 아래 모양으로 보여 준다.

   ```
   파일: knowledge/domains/pricing.md (충돌 1/3)

   내 내용:
   <<<<<<< 와 ======= 사이

   저장소 내용:
   ======= 와 >>>>>>> 사이
   ```

3. 한 메시지에 질문 하나만 한다: "내 내용 / 저장소 내용 / 둘 다 중 무엇을 남길까요?"
   - "둘 다"면 두 내용을 합친 문장을 보여 주고 그대로 쓸지 묻는다.
4. 답대로 그 부분을 고치고 `<<<<<<<`, `=======`, `>>>>>>>` 표시를 지운다.
5. 고친 부분을 다시 보여 주고 맞는지 확인받은 뒤 다음 부분으로 간다.
6. 파일의 모든 부분이 끝나면 `git add <파일>`한다.
7. 모든 파일이 끝나면 `grep -rn '^<<<<<<<\|^>>>>>>>' <충돌했던 파일들>`이 빈 출력인지 확인하고 `git commit`으로 합치기를 마친다.

버전 파일(`.codex-plugin/plugin.json` 등)과 `CHANGELOG.md`가 충돌하면 저장소 내용을 남긴다.
그다음 SKILL.md 7단계에서 버전을 다시 올린다.
이 경우만 묻지 않고 저장소 내용을 고른다. 고른 뒤 그렇게 했다고 알린다.

중간에 그만두려면 `git merge --abort`로 합치기 전으로 돌린다. 내 커밋은 그대로 남는다.
