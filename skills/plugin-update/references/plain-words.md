# 쉬운 말

| 깃 용어 | 사람에게 하는 말 |
|---------|------------------|
| clone | 저장소를 내 컴퓨터에 내려받은 폴더 |
| pull | 저장소의 최신 내용을 내 폴더로 받기 |
| 브랜치 | 내 변경만 따로 모아 두는 작업 칸 |
| 커밋 | 지금까지 바꾼 것을 설명과 함께 저장한 지점 |
| push | 내 작업 칸을 저장소에 올리기 |
| PR(Pull Request) | 내 작업 칸을 본 내용에 합쳐 달라는 요청서 |
| merge(병합) | 요청서를 받아들여 본 내용에 합치기 |
| 충돌 | 같은 부분을 나와 다른 사람이 다르게 고쳐서 하나를 골라야 하는 상태 |
| main | 모두가 받는 본 내용 |
| 태그 | 버전 번호를 붙여 둔 지점 |
| upgrade | 합쳐진 최신 플러그인을 내 Codex에 적용하기 |
