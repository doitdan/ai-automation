# Installation

Codex

```bash
codex plugin marketplace add <git-url>
codex plugin add ai-automation@ai-automation
```

Claude Code

```
/plugin marketplace add <git-url>
/plugin install ai-automation@ai-automation
```

Gemini CLI

```bash
gemini extensions install <git-url>
```
