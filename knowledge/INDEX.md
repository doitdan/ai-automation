# 지식 색인

AI가 조사하거나 사람에게 들어서 알게 된 사실과 자료는 모두 여기에 주제별로 모은다.
스킬은 사실을 본문에 적지 않고 이 색인이 가리키는 파일을 읽는다.

## 주제 파일 형식

```markdown
# <주제>

확인한 날: YYYY-MM-DD

## <항목>

<사실> (출처: <URL, 문서 경로, 또는 알려 준 사람의 역할>, YYYY-MM-DD)
```

## 추가·갱신 규칙

- 작업 중에 찾은 사실이나 자료를 다음에도 쓸 것 같으면 대화에만 두지 않고 주제 파일에 저장한다.
- 저장하기 전에 위 표에서 같은 주제를 찾는다. 있으면 그 파일을 고친다. 비슷한 이름의 새 파일이나 `-v2` 파일을 만들지 않는다.
- 사실마다 출처와 날짜를 적는다. 출처를 댈 수 없는 사실은 저장하지 않는다.
- 저장한 내용이 이미 있는 내용과 다르면 원출처에서 다시 확인한 뒤 고친다. 무엇이 어떻게 바뀌었는지 사람에게 알린다.
- 파일을 고치면 맨 위 `확인한 날`을 고친 날로 바꾼다.
- 새 파일을 만들면 위 표에 한 줄을 더한다. `다시 확인하는 주기`는 사람에게 물어 적는다.
- 결정이나 밖으로 나가는 결과물의 근거로 쓰기 전에 `다시 확인하는 주기`가 지났으면 원출처에서 다시 확인한다.
- 사실이 틀려서 결과가 틀렸으면 주제 파일을 고친다. 스킬 본문에 예외 문장을 더하지 않는다.
- 고객사 이름, 수신자, 계정 정보, 개인정보, 비밀값은 저장하지 않는다. 이 저장소는 팀 전체가 설치한다.
- 쓰는 곳은 플러그인 캐시가 아니라 설정의 `pluginRepository`다. 커밋과 푸시는 사람이 요청할 때만 하고, 할 때는 `AGENTS.md`의 버전 규칙을 따른다.
